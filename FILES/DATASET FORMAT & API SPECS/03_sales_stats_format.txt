dobby Challenge — Format δεδομένων
ΣΥΝΟΛΟ ΔΕΔΟΜΕΝΩΝ: ΣΤΑΤΙΣΤΙΚΑ ΠΩΛΗΣΕΩΝ ΑΝΑ ΠΡΟΪΟΝ (sales stats)
=====================================================================

ΤΙ ΠΕΡΙΕΧΕΙ
-----------
Συγκεντρωτικά στοιχεία πωλήσεων για μια χρονική περίοδο. Μία εγγραφή
για κάθε προϊόν που πουλήθηκε στην περίοδο, με:
  - πόσα τεμάχια πουλήθηκαν,
  - τι έσοδα έφεραν,
  - πώς μοιράζονται ανά κατάλογο (menu).

Δεν περιέχει μεμονωμένες συναλλαγές· αυτές βρίσκονται στις Παραγγελίες.

ΓΕΝΙΚΟΙ ΚΑΝΟΝΕΣ
---------------
  - Όλα τα ποσά είναι ακέραιοι σε ΛΕΠΤΑ του ευρώ (π.χ. 640 = 6,40 €).
  - Η χρονική περίοδος ορίζεται στο αίτημα (από / έως) και δεν
    περιέχεται στην απόκριση.


ΔΟΜΗ
====

[
  {
    "id": "<string>",
    "name_gr": "<string>",
    "name_en": "<string>",
    "internal_name": "<string>",
    "category": {
      "id": "<string>",
      "internal_name": "<string>",
      "name_gr": "<string>",
      "name_en": "<string>"
    },
    "price": <integer>,
    "quantity": <integer>,
    "total_amount": <integer>,
    "discount_types": {},
    "sources": [                                // προαιρετικό
      {
        "source": { "menu_id": "<string>", "menu_name": "<string>" },
        "quantity": <integer>,
        "total_amount": <integer>
      }
    ]
  }
]


ΠΕΡΙΓΡΑΦΗ ΠΕΔΙΩΝ
================
id                 Αναγνωριστικό του προϊόντος.
name_gr, name_en,
  internal_name    Όνομα του προϊόντος στα ελληνικά, στα αγγλικά και
                   εσωτερικό όνομα.
category           Κατηγορία του προϊόντος (id και ονόματα),
                   π.χ. «Πίτσες» / «Pizza».
price              Τιμή μονάδας αναφοράς του προϊόντος.
quantity           Συνολικά τεμάχια που πουλήθηκαν στην περίοδο.
total_amount       Συνολικά έσοδα από το προϊόν στην περίοδο.
discount_types     Εκπτώσεις στην περίοδο, ομαδοποιημένες ανά είδος
                   (κενό {} αν δεν υπήρξαν).
sources[]          Ανάλυση πωλήσεων ανά κατάλογο (προαιρετικό).
  .source            Ο κατάλογος: menu_id, menu_name
                     (π.χ. «Βασικός κατάλογος», «Brunch»).
  .quantity          Τεμάχια που πουλήθηκαν από αυτόν τον κατάλογο.
  .total_amount      Έσοδα από αυτόν τον κατάλογο.


ΧΡΗΣΙΜΕΣ ΣΗΜΕΙΩΣΕΙΣ
===================
1. Το price ΔΕΝ είναι μέση τιμή. Η μέση τιμή πώλησης ανά τεμάχιο είναι
   total_amount ÷ quantity (επηρεάζεται από κανάλι, extras, χρεώσεις
   και εκπτώσεις).

2. Τα sources δεν αθροίζουν πάντα στο σύνολο: πωλήσεις χωρίς
   κατάλογο-πηγή δεν εμφανίζονται στο sources.

3. Για πρόβλεψη ζήτησης χρειάζεστε χρονοσειρά: ζητήστε στατιστικά ανά
   ημέρα, ή χτίστε τη χρονοσειρά από τις Παραγγελίες
   (items[].added_at ή created_at).

4. Τα στατιστικά δεν δείχνουν ποια προϊόντα αγοράζονται μαζί. Για τις
   έξυπνες προτάσεις χρησιμοποιήστε τις Παραγγελίες.

5. Σύνδεση με άλλα σύνολα:
   id                 →  id στον Κατάλογο προϊόντων
                      →  items[].product_id στις Παραγγελίες
   sources[].source   →  items[].source στις Παραγγελίες
